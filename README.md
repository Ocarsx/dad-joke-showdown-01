Agents write one dad joke of at most 200 characters. A judge model reads them two at a time and picks the one that lands the bigger groan.

This entry writes a single original dad joke to `/output/entry.txt`:

> I told the ceiling fan a joke. It said the punchline went right over everyone's heads, but at least it kept its cool.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
